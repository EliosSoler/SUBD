1. Программный интерфейс
==========================

Программный интерфейс СУБД — это набор функций модуля ``db.py``:

- ``create_table`` — создать таблицу;
- ``drop_table`` — удалить таблицу;
- ``alter_table`` — изменить структуру таблицы;
- ``insert`` — добавить строку в таблицу;
- ``select`` — получить все строки таблицы.

**Принцип работы:** при успехе функция завершается **молча**.
При ошибке — кидает **исключение**. Пользователь сам решает,
что выводить и как обрабатывать ошибку.

2. Описание функций
=====================


2.1. create_table
-------------------

**Назначение:** создать новую таблицу в базе.

**Параметры:**

- ``table_name`` — имя создаваемой таблицы (строка);
- ``columns`` — список колонок таблицы (список строк).

**Вход:** ``create_table("users", ["id", "name", "age"])``

**Выход:** нет. Успех = функция завершилась без исключения.

**Исключение:** ``TableAlreadyExists`` — если таблица уже есть.

**Процесс:**

1. Загрузить схему базы.
2. Проверить, нет ли таблицы с таким именем.
   Если есть — кинуть ``TableAlreadyExists``.
3. Добавить таблицу в схему.
4. Сохранить схему.
5. Создать пустой файл данных для таблицы.

|


2.2. drop_table
-----------------

**Назначение:** удалить таблицу из базы.

**Параметры:**

- ``table_name`` — имя удаляемой таблицы (строка).

**Вход:** ``drop_table("users")``

**Выход:** нет. Успех = функция завершилась без исключения.

**Исключение:** ``TableNotFound`` — если таблицы нет.

**Процесс:**

1. Загрузить схему базы.
2. Проверить, есть ли таблица с таким именем.
   Если нет — кинуть ``TableNotFound``.
3. Удалить таблицу из схемы.
4. Сохранить схему.
5. Очистить файл данных таблицы.

|


2.3. alter_table
------------------

**Назначение:** изменить список колонок у существующей таблицы.

**Параметры:**

- ``table_name`` — имя таблицы (строка);
- ``new_columns`` — новый список колонок (список строк).

**Вход:** ``alter_table("users", ["id", "name", "age", "email"])``

**Выход:** нет. Успех = функция завершилась без исключения.

**Исключение:** ``TableNotFound`` — если таблицы нет.

**Процесс:**

1. Загрузить схему базы.
2. Проверить, есть ли таблица.
   Если нет — кинуть ``TableNotFound``.
3. Заменить список колонок в схеме.
4. Сохранить схему.

**Примечание:** данные в файле таблицы не изменяются.

|


2.4. insert
-------------

**Назначение:** добавить новую строку в таблицу.

**Параметры:**

- ``table_name`` — имя таблицы (строка);
- ``values`` — список значений новой строки (список строк).

**Вход:** ``insert("users", ["1", "Вася", "20"])``

**Выход:** нет. Успех = функция завершилась без исключения.

**Исключения:**

- ``TableNotFound`` — если таблицы нет;
- ``ValueError`` — если число значений не совпадает с числом колонок.

**Процесс:**

1. Загрузить схему базы.
2. Проверить, есть ли таблица.
   Если нет — кинуть ``TableNotFound``.
3. Получить список колонок таблицы.
4. Проверить, что число значений совпадает с числом колонок.
   Если нет — кинуть ``ValueError``.
5. Прочитать текущие строки из файла таблицы.
6. Добавить новую строку.
7. Сохранить файл.

|


2.5. select
-------------

**Назначение:** получить все строки таблицы.

**Параметры:**

- ``table_name`` — имя таблицы (строка).

**Вход:** ``select("users")``

**Выход:** матрица (список списков) со всеми строками таблицы.

**Исключение:** ``TableNotFound`` — если таблицы нет.

**Процесс:**

1. Загрузить схему базы.
2. Проверить, есть ли таблица.
   Если нет — кинуть ``TableNotFound``.
3. Прочитать все строки из файла таблицы.
4. Разбить каждую строку по символу ``|``.
5. Вернуть матрицу.

**Пример выхода:** ::

   [["id", "name", "age"], ["1", "Вася", "20"], ["2", "Петя", "22"]]

\


3. Исключения
===============

В СУБД используются следующие исключения:

- ``DBError`` — базовое исключение СУБД; от него наследуются остальные;
- ``TableAlreadyExists`` — попытка создать уже существующую таблицу;
- ``TableNotFound`` — операция с несуществующей таблицей;
- ``ValueError`` — неверное число значений при вставке
  (стандартное исключение Python).


4. Тестирование
=================

Функции протестированы в файле ``tests.py``. Проверены успешные
и ошибочные сценарии:

- создание таблицы (успех / повторно — ``TableAlreadyExists``);
- добавление данных (успех / неверное число значений — ``ValueError``);
- операция с несуществующей таблицей — ``TableNotFound``;
- чтение данных (``select`` возвращает матрицу);
- изменение структуры;
- удаление таблицы (успех / повторно — ``TableNotFound``).

Дополнительно в файле ``tests_uncaught.py`` показано аварийное
завершение программы при непойманном исключении.
