1. Программный интерфейс
==========================

Программный интерфейс СУБД — это методы класса ``Database``
из модуля ``db.py``:

- ``create_table`` — создать таблицу;
- ``drop_table`` — удалить таблицу;
- ``alter_table`` — изменить структуру таблицы;
- ``insert`` — добавить строку в таблицу;
- ``select`` — получить строки таблицы с выбором полей.

**Принцип работы:** при успехе метод завершается **молча**.
При ошибке — кидает **исключение**. Пользователь сам решает,
что выводить и как обрабатывать ошибку.

Объект класса создаётся один раз::

    db = Database("database")

Схема читается один раз при создании объекта и хранится в памяти.

2. Описание функций
=====================


2.1. create_table
-------------------

**Назначение:** создать новую таблицу в базе.

**Параметры:**

- ``table_name`` — имя создаваемой таблицы (строка);
- ``columns`` — список колонок таблицы (список строк).

**Вход:** ``db.create_table("users", ["id", "name", "age"])``

**Выход:** нет. Успех = метод завершился без исключения.

**Исключение:** ``TableAlreadyExists`` — если таблица уже есть.

**Процесс:**

1. Проверить, нет ли таблицы с таким именем в схеме.
   Если есть — кинуть ``TableAlreadyExists``.
2. Добавить таблицу в схему.
3. Сохранить схему.
4. Создать пустой файл данных для таблицы.

|


2.2. drop_table
-----------------

**Назначение:** удалить таблицу из базы.

**Параметры:**

- ``table_name`` — имя удаляемой таблицы (строка).

**Вход:** ``db.drop_table("users")``

**Выход:** нет. Успех = метод завершился без исключения.

**Исключение:** ``TableNotFound`` — если таблицы нет.

**Процесс:**

1. Проверить, есть ли таблица с таким именем.
   Если нет — кинуть ``TableNotFound``.
2. Удалить таблицу из схемы.
3. Сохранить схему.
4. Удалить файл данных таблицы через ``os.remove``.

|


2.3. alter_table
------------------

**Назначение:** изменить список колонок у существующей таблицы.

**Параметры:**

- ``table_name`` — имя таблицы (строка);
- ``new_columns`` — новый список колонок (список строк).

**Вход:** ``db.alter_table("users", ["id", "name", "age", "email"])``

**Выход:** нет. Успех = метод завершился без исключения.

**Исключение:** ``TableNotFound`` — если таблицы нет.

**Процесс:**

1. Проверить, есть ли таблица.
   Если нет — кинуть ``TableNotFound``.
2. Заменить список колонок в схеме.
3. Сохранить схему.

**Примечание:** данные в файле таблицы не изменяются.

|


2.4. insert
-------------

**Назначение:** добавить новую строку в таблицу.

**Параметры:**

- ``table_name`` — имя таблицы (строка);
- ``values`` — список значений новой строки (список строк).

**Вход:** ``db.insert("users", ["1", "Вася", "20"])``

**Выход:** нет. Успех = метод завершился без исключения.

**Исключения:**

- ``TableNotFound`` — если таблицы нет;
- ``ValueError`` — если число значений не совпадает с числом колонок.

**Процесс:**

1. Проверить, есть ли таблица.
   Если нет — кинуть ``TableNotFound``.
2. Получить список колонок таблицы.
3. Проверить, что число значений совпадает с числом колонок.
   Если нет — кинуть ``ValueError``.
4. Прочитать текущие строки из файла таблицы.
5. Добавить новую строку.
6. Сохранить файл.

|


2.5. select
-------------

**Назначение:** получить строки таблицы с выбором полей.

**Параметры:**

- ``table_name`` — имя таблицы (строка);
- ``fields`` — список полей через запятую (строка). По умолчанию ``"*"`` —
  все поля.

**Вход:**

- ``db.select("users")`` — все поля;
- ``db.select("users", "name,age")`` — только name и age;
- ``db.select("users", "age,name")`` — порядок другой;
- ``db.select("users", "name,name")`` — дубли разрешены.

**Выход:** матрица (список списков). Первая строка — имена выбранных
полей, остальные — значения.

**Исключения:**

- ``TableNotFound`` — если таблицы нет;
- ``ColumnNotFound`` — если запрошено несуществующее поле.

**Процесс:**

1. Проверить, есть ли таблица.
   Если нет — кинуть ``TableNotFound``.
2. Если ``fields == "*"`` — выбрать все колонки.
   Иначе — разбить строку по запятой.
3. Для каждого поля проверить, что оно есть в схеме.
   Если нет — кинуть ``ColumnNotFound``.
4. Найти индексы выбранных колонок.
5. Первая строка матрицы — имена полей.
6. Для каждой строки данных — собрать значения по индексам.
7. Вернуть матрицу.

**Пример выхода:** ::

   [["id", "name", "age"], ["1", "Вася", "20"], ["2", "Петя", "22"]]

\


3. Исключения
===============

В СУБД используются следующие исключения:

- ``DBError`` — базовое исключение СУБД; от него наследуются остальные;
- ``TableAlreadyExists`` — попытка создать уже существующую таблицу;
- ``TableNotFound`` — операция с несуществующей таблицей;
- ``ColumnNotFound`` — запрошено несуществующее поле;
- ``ValueError`` — неверное число значений при вставке
  (стандартное исключение Python).


4. Тестирование
=================

Функции протестированы в файле ``tests.py`` через модуль ``unittest``.
**Класс** на каждую функцию, **метод** на каждый сценарий:

- создание таблицы (успех / повторно — ``TableAlreadyExists``);
- добавление данных (успех / неверное число значений — ``ValueError``);
- операция с несуществующей таблицей — ``TableNotFound``;
- чтение данных (``select`` возвращает матрицу);
- выбор полей (любой порядок, дубли, ``ColumnNotFound``);
- изменение структуры;
- удаление таблицы (успех / повторно — ``TableNotFound``).

Используются ``assertEqual`` и ``assertRaises``, а также
``setUp``/``tearDown`` для подготовки и очистки.
